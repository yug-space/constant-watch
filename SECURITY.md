# Reporting security issues

For a vulnerability involving capture privacy, local API access, credential redaction or MCP data exposure, use GitHub's private vulnerability reporting on this repository. Do not post actual journals, access tokens or personal screen captures in public issues. Use a minimal synthetic example.

This is preview software. Capture protections and secret redaction are best-effort. A connected MCP client can read the journal, and other processes running as the same user can access the loopback service and local data. See the README for limits and controls.
